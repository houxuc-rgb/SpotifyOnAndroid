# Spotify-style Music App (Android)

A full-stack music streaming app: a native Android client backed by a Kotlin/Ktor server.

## Android client

- Jetpack Compose UI, MVVM architecture
- Hilt dependency injection
- Retrofit for networking, Room for local persistence
- Repository pattern; home / playlist / favorites / player features

## Backend

- Kotlin + Ktor server serving playlists, feed, and audio streaming

## Stack

Kotlin | Jetpack Compose | Hilt | Retrofit | Room | Ktor
